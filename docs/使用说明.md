# 打坐倒计时小窗 · 使用说明

一个放在游戏画面上的打坐倒计时贴纸：只有一串数字，不会挡住操作，可以锁定成完全不碰鼠标的一层。

![空闲状态](../assets/preview-idle.png)

- 相关：[项目说明与构建方式](../README.md)
- 版本：1.0.0（Windows 7 SP1 / 10 / 11，32 位 / 64 位）

## 1. 安装

不需要安装。

1. 把 `MeditationTimer.exe` 拷到任意**可写目录**（桌面、D 盘某个文件夹都行）。
2. 双击运行。

两点注意：

- **别放在 `C:\Program Files`** 之类需要管理员才能写的地方 —— 程序能跑，但设置存不下来（配置要写在 exe 旁边）。
- 第一次运行 Windows 可能弹「Windows 已保护你的电脑」，点 **更多信息 → 仍要运行**。这是因为没有购买代码签名证书，不是文件损坏。

想连设置一起带走：把 exe 和 `meditation.ini` 放同一个文件夹一起拷，对方打开就是你调好的样子。

## 2. 启动

| 你的情况 | 怎么启动 |
|---|---|
| 只想看倒计时、不需要在游戏里按键 | 直接双击 exe |
| 想用 `F9` 之类的全局快捷键 | **右键 exe → 以管理员身份运行**，或双击 `run-as-admin.bat` |

为什么快捷键要管理员：游戏一般是以管理员权限启动的，Windows 不允许普通权限的程序接收高权限窗口的按键。
不提权时程序一切正常，只是**游戏窗口在前台时按热键没反应**（切到桌面上按是有效的）。

想永久生效：右键 exe → 属性 → 兼容性 → 勾选「以管理员身份运行此程序」。

## 3. 界面说明

- **数字区**：剩下的时间。默认显示**剩余秒数**（`180` → `179` → … → `0`），也可以切成 `分:秒`（`03:00`）。
- **背景胶囊**：深色圆角底，宽度跟着数字走，可以调透明度，也可以调成全透明（只剩数字）。
- **没有任务栏按钮**：程序是工具窗口，只出现在**托盘**里。找不到窗口就点托盘图标。

托盘图标的颜色同时表示状态：

| 图标颜色 | 含义 |
|---|---|
| 灰 | 等待开始（还没开始 / 已经重置） |
| 青 | 正在计时 |
| 黄 | 已暂停 |
| 红 | 到点了 |

## 4. 基本操作

| 操作 | 效果 |
|---|---|
| 把鼠标移到数字上，左键拖动 | 移动位置 |
| 左键单击 | 暂停 / 继续（只在计时中或暂停时有效） |
| 左键双击 | 从完整时长重新开始 |
| `Ctrl` + 滚轮上下 | 缩放窗口（每次 ±8%，范围 132×44 ~ 320×96 逻辑像素，以左上角为基准） |
| 右键 | 打开菜单 |
| 按 `F9`（可改） | 从完整时长重新开始（全局，游戏里也有效） |
| 托盘图标双击 | 从完整时长重新开始 |

> 全透明状态下，只有数字那一小块能点到（约 50×21 逻辑像素），其余区域鼠标直接穿透到游戏里。
> 如果连数字也不想挡，用托盘菜单的「隐藏小窗」。

## 5. 右键菜单逐项说明

![右键菜单](../assets/preview-menu.png)

| 菜单项 | 作用 |
|---|---|
| **重新计时（N 秒）** | 从完整时长重新开始。括号里是当前时长 |
| **继续** / **暂停** | 在暂停与继续之间切换；等待开始和已到点时是灰的 |
| **打坐时长** ▸ | 预设 `1 / 2 / 3 / 5 / 10 / 15 / 30` 分钟；「自定义…」可以填 1~180 分钟。改时长会立刻按新时长重置 |
| **时间格式** ▸ | 「剩余秒数（180）」或「分:秒（03:00）」 |
| **字号** ▸ | 「自动（随窗口大小）」（约窗口高度的 40%）、`14 / 18 / 22 / 28 / 34 px`、「自定义…」（8~96 px） |
| **文字颜色** ▸ | 白 / 黑 / 亮黄 / 青 / 橙 / 绿，或「自定义…」用取色板挑；当前颜色前面带 ✓ |
| **描边颜色** ▸ | 「自动（跟文字反色）」（默认，浅底深字自动出深描边）、「无描边」、6 种预设、「自定义…」。描边的深浅会跟着背景透明度自动调整 |
| **背景透明度** ▸ | 全透明 / 30% / 50% / 70% / 85% / 100% |
| **置顶** | 是否始终压在其他窗口（包括游戏）上面，带勾表示已开 |
| **锁定（鼠标穿透）** | 锁定后整窗不再接收鼠标：点不到、拖不动、右键也不弹菜单。**解锁只能用托盘菜单**，见下一节 |
| **设置快捷键…** | 弹窗里直接按要用的组合键（如 `Ctrl+Alt+F5`）即可录制；单键也行 |
| **快捷键：xxx** | 只显示当前注册状态。显示「未注册」= 这个组合被别的程序占了，换一个 |
| **退出** | 退出程序（会顺手保存位置） |

菜单是深色主题，一级和二级菜单配色一致。

## 6. 托盘图标

托盘图标是程序唯一的常驻入口，**右键**它：

| 菜单项 | 作用 |
|---|---|
| **隐藏小窗 / 显示小窗** | 临时把小窗藏起来。计时继续在跑，托盘图标的颜色和提示照常更新 |
| **重新计时** | 同小窗菜单 |
| **置顶** | 同小窗菜单（带勾表示已开） |
| **锁定（鼠标穿透）** | 同小窗菜单。**小窗锁定后无法再用它自己的菜单，只能从这里解锁** |
| **退出** | 退出程序 |

鼠标停在托盘图标上会显示剩余时间，比如「打坐 180」。

> Windows 11 默认把新出现的托盘图标收在任务栏的 `^`（溢出区）里。点 `^` 能找到它，
> 把它拖到任务栏上就会一直显示。

## 7. 到点提醒

时间到了之后：

- 数字变成 `0`（或 `00:00`）并停住；
- 数字**闪几下红色**作为提醒；
- **没有声音**，不会打断游戏音效。

想看下一轮就按 `F9`、双击小窗、或菜单里「重新计时」。

## 8. 推荐的几套搭配

**① 极简贴纸（最不碍事）**

```
背景透明度 → 全透明
字号       → 34 px
描边颜色   → 自动（跟文字反色）
锁定       → 开
```

只剩一串数字浮在画面上，点都点不到。

**② 深色胶囊（默认风格，看得清）**

```
背景透明度 → 85%
字号       → 28 px
文字颜色   → 白色
描边颜色   → 无描边
```

**③ 醒目黄字（暗色场景用）**

```
背景透明度 → 全透明
字号       → 34 px
文字颜色   → 亮黄
描边颜色   → 自动（跟文字反色）
置顶       → 开
```

## 9. 配置文件

设置都存在 exe 旁边的 `meditation.ini`，菜单里改一下就会立刻写回。字段、默认值、取值范围见
[README 的配置表](../README.md#配置)。

三个注意事项：

1. **手动改 ini 之前先退出程序**，否则程序下一次保存会把你改的内容覆盖掉。
2. 位置 `x` / `y` 按**逻辑像素**存（150% 缩放下 176×54 的窗口会显示成 264×81）。
3. 删掉 `meditation.ini` = 恢复出厂默认（默认 85% 不透明、白字、180 秒、`F9`、屏幕上方居中）。

## 10. 常见问题

**Q：按 F9 没反应？**
A：三种可能 —— ① 没用管理员身份运行（游戏在前台时按键会被 UIPI 挡掉）；② 快捷键被别的软件占了，
右键菜单底部会显示「快捷键：未注册」，换一个组合就好；③ 程序已经是「暂停」状态，`F9` 是重新计时不是继续，
点一下数字或菜单「继续」。

**Q：窗口不见了？**
A：如果背景是全透明的，在画面上一串白字确实容易看漏；点托盘图标「显示小窗」能确认它还在。
位置如果跑到屏幕外（比如换过显示器/缩放比例），退出程序、删掉 `meditation.ini` 里的 `x` 和 `y` 两行，
再启动就会回到屏幕上方居中。

**Q：点不到、也拖不动？**
A：处于锁定状态。托盘图标右键 →「锁定（鼠标穿透）」取消勾选。

**Q：全透明之后为什么还能点到数字那块？**
A：故意留的 —— 不然就再也拖不动、也打不开菜单了。这块区域正好是数字本身（约 50×21 逻辑像素），
其余区域全部穿透给游戏。真的一点都不想挡，用托盘「隐藏小窗」。

**Q：白色数字在明亮的画面上看不见？**
A：右键「描边颜色」→「自动（跟文字反色）」，浅色底上会自动出深色描边；或者把文字颜色换成亮黄 / 青色。

**Q：托盘里找不到图标？**
A：Windows 11 把新图标默认折叠进 `^` 溢出区；点开能看到，拖到任务栏上就常驻了。

**Q：改了设置，下次打开又变回去了？**
A：exe 放在了不可写目录（如 `Program Files`），配置存不下来。把整个文件夹挪到桌面或 D 盘。

**Q：能同时开两个吗？**
A：可以，但**全局快捷键只有一个能注册成功**，第二个实例的菜单会显示「快捷键：未注册」。一般没必要开两个。

**Q：换电脑 / 换分辨率后位置偏了？**
A：位置按逻辑像素记，缩放比不同会偏。删掉 ini 里的 `x` / `y` 重新摆一次即可。

**Q：杀毒软件报可疑？**
A：未签名的小体积 exe、又要注册全局热键、还要创建分层窗口，容易命中启发式规则。加入信任即可。
想彻底解决得买代码签名证书。

**Q：会往系统里写什么？**
A：只写 exe 旁边那个 `meditation.ini`。不写注册表、不装服务、不联网。

## 11. 复位、备份与卸载

- **复位**：退出程序 → 删掉 `meditation.ini` → 重新启动。
- **备份设置**：复制 `meditation.ini`；换机器时和 exe 放一起即可。
- **卸载**：退出程序 → 删掉那个文件夹。没有注册表项、没有残留服务。
